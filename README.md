# edge

Command-line interface for DECA Edge. This repository publishes releases only.
The source lives in the private `resola-ai/deca-edge` repository.

## Install

Shared development:

```bash
curl -fsSL https://cli.edge.deca-dev.com/install.sh | sh
```

```powershell
irm https://cli.edge.deca-dev.com/install.ps1 | iex
```

```bash
brew install resola-ai/tap/deca-edge
```

```powershell
scoop bucket add resola https://github.com/resola-ai/scoop-bucket
scoop install deca-edge
```

Documentation: <https://docs.edge.deca-dev.com/guide/install-the-cli.html>

macOS binaries in v0.1.0 are not notarized.
